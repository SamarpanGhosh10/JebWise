#  JebWise — Smart Expense Tracker



JebWise is a beginner-friendly, command-line personal expense tracker built with Python. It helps users record daily expenses, review transaction history, and understand their spending habits through category-wise summaries.

I'm building JebWise as a hands-on learning project to strengthen my Python programming and data-handling skills.

##  Features

- **Record Expenses:** Enter an expense amount and category.
- **Transaction History:** View all expenses recorded during a session.
- **Total Spending:** Calculate the total amount spent.
- **Category-wise Summary:** See how much you spend on Food, Travel, Shopping, and other categories.
- **Formatted Output:** Display amounts in Indian rupees with two decimal places.

## Tech Stack

- **Language:** Python
- **Concepts:** Variables, loops, lists, dictionaries, conditional statements, and functions such as `enumerate()` and `sum()`

## Getting Started

### Prerequisites

- Python 3 installed on your computer
- A code editor such as VS Code

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/JebWise.git
   ```

2. Navigate to the project directory:

   ```bash
   cd JebWise
   ```

3. Run the program:

   ```bash
   python jebwise.py
   ```

Replace `YOUR_USERNAME` with your GitHub username.
